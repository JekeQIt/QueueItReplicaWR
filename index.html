Queue-it replica waiting room

Local copies of the four waiting room pages, running the real Queue-it engine, with a floating control panel to simulate states, model updates and themes.

BeforePre-queue countdown and the transition into the queue QueueIn line: preview states, modelUpdated, auto-run AfterPost-queue page and its dynamic message ErrorAll error states, er=0 to er=14

Using it

  • Start the local server with node server.js and open http://localhost:8080/. You need the server to import a theme from a preview link.
  • The panel is draggable and resizable. Minimize it with – or Alt+Shift+R.
  • Theme › Import: paste a Custom Theme preview link. The before, queue, after and error previews are read and applied to all four pages.
  • Your own theme files are files/style.css and files/script.js. They are listed under Theme › Styling.

You opened this file straight from disk. Pages work, but theme import needs the local server: run node server.js in this folder.
